# Лабораторные по компьютерной графике

Вариант 3: параллелепипед (порядковый номер 27). C++20, Vulkan, GLFW, ImGui.

- **Lab1** — геометрия, проекции и трансформации. Управление возвращено в ImGui.
- **Lab2** — базовая камера, один направленный свет и материал Блинн–Фонга.
- **Lab3** — базовое текстурирование: одна текстура, staging-загрузка в GPU и динамический uniform-буфер.
- **Lab4** — карта теней направленного света через Vulkan Dynamic Rendering.

Запуск из этой папки, по одному приложению:

```powershell
.\Lab1\build.ps1 -Run
.\Lab2\build.ps1 -Run
.\Lab3\build.ps1 -Run
.\Lab4\build.ps1 -Run
```

Скрипт сам переходит в нужную папку. Все параметры меняются мышью в ImGui.
Результат сборки каждой лабы: `build-debug/vulkan-starter-app.exe` внутри её папки.
